# QA Report — Phase 2 Amend Cycle (`p2-3`)

## Amend Evaluation & Test Fix Rationale

`dev` reported a valid collection-time defect in `tests/backend/observability-and-manifest.test.ts` (`## Suspected test problem`):

- **Root cause:** Under Vitest's `jsdom` environment, global `URL` is JSDOM's `URL` constructor rather than Node's `node:url` `URL` class. Passing `new URL('../../manifest.yml', import.meta.url)` directly to Node 22's `node:fs` `readFileSync(...)` at module evaluation time threw `TypeError: The URL must be of scheme file` before any test in `tests/backend/observability-and-manifest.test.ts` could run. During `lintel lock`, that collection failure was masked because the overall `unit` group exited `1` alongside the unimplemented Phase 2 stubs.
- **Fix applied:** Updated `tests/backend/observability-and-manifest.test.ts` to import `{ fileURLToPath, URL as NodeURL } from 'node:url'` and resolve the repository manifest path via `fileURLToPath(new NodeURL('../../manifest.yml', import.meta.url))` before calling `readFileSync(..., 'utf8')`.
- **Contract & Lock-Gate Verification:**
  - Against the pre-lock Phase 2 stubs (`lintel amend` check), `tests/backend/observability-and-manifest.test.ts` now collects cleanly with zero module-load errors and fails red (`exit 1`) on its behavioral assertions against `validatePlatformManifest`, `sanitizeLogMetadata`, and `createBackendLogger` (`T-AMD-06`, `T-AMD-07`, `T-AMD-08`), while preserving all 5 Phase 2 backend test files in the `unit` group diff (`T-AMD-76`).
  - Against the current `dev` workspace implementation, all `38` tests in `tests/backend/observability-and-manifest.test.ts` execute and pass alongside the other `577` tests (`615 passed` across `9` suites).
